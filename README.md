## 📂 3. 檔案結構說明
* `index.html`：本心理測驗以「內向與外向人格傾向」為主題，透過五道單選題引導使用者進行自我探索。題目內容圍繞日常生活中常見的情境，包括在社交場合中的感受、對獨處與群體活動的偏好、面對陌生人時的反應、休息與恢復精神的方式，以及平時表達想法的習慣。

每一道題目皆提供三種選項，分別代表偏內向、中立，以及偏外向的傾向。系統會根據使用者所選擇的答案累積分數，並於測驗結束後，判斷使用者的人格傾向，分為「偏內向型人格」、「內外向平衡型人格」與「偏外向型人格」三種類型。

測驗結果頁面會清楚呈現人格類型標題，並搭配兩到三句溫和、不具標籤性的說明文字，幫助使用者理解自身特質。同時也會提供鼓勵性的文字說明，強調不同人格傾向並無好壞之分，僅是個人特質上的差異。頁面最後設置「重新測驗」按鈕，讓使用者可再次進行測驗。
* `style.css`：整體風格：簡約、溫暖、現代感

主色系：米色、淺咖啡、柔和灰

設計元素：

圓角卡片

留白充足

柔和陰影

字體：清楚易讀、帶一點人文感

動效：

點擊選項時有輕微回饋

頁面切換平順、不浮誇
